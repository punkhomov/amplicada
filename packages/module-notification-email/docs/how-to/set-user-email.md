# Выдать пользователю email

Адрес хранится в `notification_email.user_email` и редактируется в карточке пользователя
(`/admin/user/<id>`) — модуль вкладывает поля в группу security.

1. Откройте карточку пользователя в админке.
2. Заполните поле **Email** и сохраните. Сохранение админом считается подтверждением:
   `verified_at` проставляется автоматически, поле «Адрес подтверждён» станет заполненным.
3. С этого момента `resolveAddress` возвращает адрес и по нему уходят уведомления.

Ограничения:

- Пустое поле не сохраняется: очистить адрес через карточку нельзя, только SQL-ом.
- Один адрес — один пользователь (`UNIQUE`). Попытка сохранить занятый адрес вернёт ошибку
  конфликта (`409`).
- Пока `verified_at` пуст (например, выставлен вручную в БД), доставки на этот адрес нет —
  outbox-строка не создаётся.
