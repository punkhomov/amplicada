# Корпус пакетов: происхождение и условия

Настоящие пакеты, выгруженные настоящими инструментами. Нужны потому, что все остальные фикстуры
библиотеки — XML, написанный нами же: такой тест подтверждает наши представления о формате по
построению и не может их опровергнуть.

Собрано 2026-08-10 из локальной копии
[`jcputney/elearning-module-parser`](https://github.com/jcputney/elearning-module-parser).
[Исходный репозиторий опубликован по Apache 2.0](https://github.com/jcputney/elearning-module-parser/blob/main/LICENSE),
но корпус содержит материалы разных авторов. Условия для конкретных групп нужно устанавливать
по их первоисточникам; лицензия репозитория-источника сама по себе не подтверждает права на каждый
заимствованный описатель. Ниже указано, что удалось установить для каждой группы.

Сводка авторов и лицензий — в [`NOTICE.md`](NOTICE.md); копия Apache License 2.0 для тех групп,
где эта лицензия подтверждена, — в [`LICENSE-APACHE-2.0.txt`](LICENSE-APACHE-2.0.txt).

## Правило отбора

> **Описатели — дословно. Ассеты — только путями.**

`readBytes` во всей библиотеке вызывается из одного места (`readDescriptorText` в `formats/detect.ts`)
и только для описателей. Всё остальное — проверка существования файла, content-type, разрешение
точки запуска — работает по списку имён. Байты картинок, скриптов и вёрстки не читает ничто.

Поэтому на диске лежат только `*.xml`, `*.crs`, `*.au`, `*.des`, `*.cst`, `*.pre`, `*.ort`, а полный
перечень файлов исходного пакета — в `files.txt` рядом. Схемы (`*.xsd`, `*.dtd`) тоже хранятся только
путём: разборщик их не читает.

Следствие, важное для этого документа: **чужие картинки, скрипты и вёрстка здесь не
распространяются вовсе.** Список имён — факт о пакете, а не его содержимое.

Загрузка: 209 пакетов, 228 описателей, 709 путей, 2,2 МБ вместо исходных 16.

«Дословно» здесь буквально, включая переводы строк: каталог помечен в корневом `.gitattributes` как
`-text`. Git не нормализует эти файлы при сохранении или извлечении, поэтому тесты работают с
исходными байтами описателей независимо от настройки `core.autocrlf` у разработчика.

Корневая лицензия MIT распространяется на код Amplicada, но не меняет права на сторонние
материалы в этом корпусе. Для части источников ниже условия повторного распространения не
установлены; перед публичной публикацией корпуса их нужно проверить либо заменить соответствующие
описатели синтетическими фикстурами.

Читать корпус — `fixtureSource(dir)` из `src/testing/fixture-source.ts`.

## Источники

### `conformance/adl-cts/` — 189 пакетов

**ADL SCORM 2004 4th Edition Test Suite**, скопированы дословно
(`SCORM-2004-4ed-Test-Suite/software_development/TestSuite/LMSRTE/Courses/LMSTestPackage_*`).
Канонический контракт формата: если пакет из этого набора у нас не разбирается, неправы мы.

Пакеты CTS **не самодостаточны на диске** и в исходнике: их SCO собираются из общего депо
(`Courses/SCODepot/`) при развёртывании, часть `href` не резолвится ни во что. Поэтому проверка
существования файлов на этом корпусе даёт ложные срабатывания и в тесте отключена.

Правообладатель — Advanced Distributed Learning Initiative. В
[репозитории Test Suite](https://github.com/adlnet/SCORM-2004-4ed-Test-Suite#license)
ADL указывает лицензию Apache 2.0; это первичный источник условий для этой группы.

### `scorm12/`, `scorm2004/` — 12 пакетов

**Rustici Software** (http://www.scorm.com) — их образцовые курсы, шапка стоит в каждом манифесте:
`Provided by Rustici Software`. Курс про гольф (`golf-one-file-per-sco`) — самый растиражированный
образец SCORM вообще; текст уроков в нём взят с Wikipedia (в HTML стоит `AddLicenseInfo("Wikipedia",
…)`), но HTML мы и не копируем.

Исключение — `scorm12/prerequisites`, `scorm12/malformed-xml`, `scorm12/nested-organization`: шапки
Rustici в них нет, идентификаторы синтетические (`test_prerequisites_manifest`). Похоже, написаны
самим образцом, то есть под его Apache 2.0.

### `cmi5/` — 3 пакета

**Rustici Software, Apache 2.0** — единственный источник, где лицензия объявлена прямо в файлах:
`Copyright 2021 Rustici Software / Licensed under the Apache License, Version 2.0`.

### `xapi/basic-course`

Идентификаторы вида `http://example.com/activities/basic-course`, описание «A simple test course for
xAPI/TinCan package parsing» — написан самим образцом, Apache 2.0.

### `aicc/` — 4 пакета

Разнородные:

| Пакет | Происхождение |
|---|---|
| `complex`, `pre-ort` | `Course_Creator=Example Corp` / `Test Vendor` — синтетика образца, Apache 2.0 |
| `basic` | `Course_Creator=Profiscience Partners`, «UniversitySite AICC Testing Tool» — вывод чужого инструмента проверки |
| `multiline-description` | `Course_Creator=lifespeak`, курс «Achieving Work-Life Balance», система `opslearning.lifespeak.com` — **описатель настоящего чужого курса**, условия неизвестны |

`multiline-description` оставлен сознательно: ценность его в том, что это единственный в корпусе
descriptor, выгруженный настоящей промышленной системой, а не написанный для теста, — на нём видно,
как выглядят многострочные значения в CSV на практике. Копируется только описатель (название,
создатель, структура), содержимого курса в нём нет. Если правообладатель будет против — заменить на
синтетический эквивалент; технической ценности потеряется мало, вся она в кавычках и переносах.

## Как обновить или расширить

Скрипт переноса одноразовый и в репозиторий не клался: процедура полностью описана выше — обойти
каталог пакета, скопировать файлы с описательными расширениями, сложить полный перечень в
`files.txt`. Полный CTS — все 189 — уже здесь; расширять нечего.
