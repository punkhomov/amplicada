# Первые события за пять минут

Научимся включать сбор, находить события в админке и менять настройки. Предполагается, что
инфраструктура поднята (`pnpm infra:up`) и приложение запущено (`pnpm dev`).

## 1. Проверьте, что сбор включён

Запросите bootstrap-конфиг трекера:

```bash
curl -s http://localhost:3000/api/metrics/context
```

Ожидаемый ответ: `{"enabled":true,"sampleRates":{"pageview":1,"ui":0.1},"limits":{...}}`.
Если `enabled:false` — включите сбор в настройках (шаг 3).

## 2. Походите по приложению

Откройте <http://localhost:5173>, авторизуйтесь и перейдите по двум-трём страницам.
Трекер отправляет `page.view` на смену маршрута: пачками раз в 10 секунд и через
`navigator.sendBeacon` при уходе со страницы.

## 3. Посмотрите ленту

Откройте админ-приложение «Метрики»: `/admin/apps/metrics` → вкладка «События». Там будут
строки `page.view` с шаблоном маршрута (`/support/:id`), временем и псевдонимами актора и
сессии. Обновите страницу приложения — лента обновляется сама раз в 15 секунд.

То же можно посмотреть через API:

```bash
curl -s "http://localhost:3000/api/metrics/events?kind=page&limit=5"
```

## 4. Поменяйте настройки

В админ-приложении откройте вкладку «Настройки»: выключите «Сбор включён» и сохраните.
Трекер перестанет отправлять события, а `POST /api/metrics/collect` будет отвечать
`{"accepted":0,...,"disabled":true}`. Включите сбор обратно.

Там же настраиваются retention (дни) и доли сэмплирования просмотров и кликов.
